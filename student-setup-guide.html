04

Click the + button next to Instructions. A text box will appear. Copy and paste the text below exactly as written.

How to use it
For each report section:
  • Start a new conversation inside your project
  • Upload your project synopsis when Claude asks
  • Paste the section you want to humanize
  • Tell Claude which section it is (Abstract, Introduction, etc.)
  • Get draft → audit → final pass output
  • Copy the final version into your report
Example prompt to paste after uploading synopsis:
"This is my Introduction chapter. Humanize it."
— then paste your text below.
